## Escola Horizonte — Site Institucional Escolar

Projeto desenvolvido como estudo de caso com foco em organização da comunicação digital escolar.

### Funcionalidades
- Site responsivo
- Central da Família
- Cardápio Digital
- Página de Matrículas
- Header e Footer dinâmicos
- QR Code para acesso rápido

### Tecnologias
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

Projeto criado para demonstração em portfólio.
